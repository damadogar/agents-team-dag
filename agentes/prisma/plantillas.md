# plantillas.md — Plantillas de entregables

Plantillas estándar de Prisma. Toda entrega termina con **"Próximos pasos"**
y **"Criterios de éxito medibles"**. Lo que cubra trabajo fuera del foco central se
marca **`[COBERTURA ADJUNTA]`** con su handoff (ver
[gobernanza-y-colaboracion.md](gobernanza-y-colaboracion.md) §4.1).

---

## 1. Informe ejecutivo (1 página)

```
# Informe — <pregunta>
Pregunta de negocio: ...
Hallazgo / respuesta (al frente): ...
Recomendación accionable: ...
Impacto esperado (con rango): ...
Incertidumbre y limitaciones: ...
Próximos pasos · Criterios de éxito medibles: ...
```

```

Encuadre: predictivo | causal; variable objetivo; grain
Datos: fuente (core/semantic layer), periodo, volumen, calidad
Método: enfoque, features, validación (split/CV), métricas
Resultados: desempeño vs baseline + intervalos
Análisis de errores / sesgo: ...
Limitaciones y supuestos: ...
Reproducibilidad: versión datos/código, semilla, tracking

```
