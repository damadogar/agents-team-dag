# Checklists — radar

## Pre-lanzamiento dominio/site

```
[ ] GSC verificado + sitemap enviado
[ ] HTTPS, canonical, robots OK
[ ] Home + money pages indexables
[ ] Titles/H1 únicos
[ ] CWV baseline
[ ] Analytics + consent alineado (legal/sello)
[ ] Tracking brand vs non-brand definido
```

## Post-migración

```
[ ] Mapa 301 completo
[ ] Sitemaps nuevos
[ ] Internal links actualizados
[ ] GSC Inspection muestreo
[ ] Monitoreo 14–45 días
```
