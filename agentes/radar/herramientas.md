# Herramientas SEO — catálogo neutral (mantener al día)

> **Disciplina de vigencia:** precios, límites de plan, nombres de features y
> cobertura de “AI visibility” cambian. Antes de recomendar un plan concreto,
> verifica la fuente oficial del vendor o marca **[no verificado / a fecha]**.
> Este archivo lista *roles* de herramienta; no es una lista de compra fija.

## Cómo actualizar este mapa (obligatorio en auditorías)

1. Confirmar first-party: GSC / Bing Webmaster / GBP.
2. Revisar release notes de Ahrefs, Semrush, Screaming Frog (últimos 90 días si el brief es estratégico).
3. Anotar fecha de revisión en el entregable.
4. Preferir evidencia first-party sobre estimaciones de terceros.

## Principios de selección

1. **Primero GSC** si el dominio está verificado.
2. Una suite de research basta al inicio (Ahrefs *o* Semrush); no dupliques costo sin pregunta nueva.
3. Crawler de escritorio para migraciones y JS pesado.
4. Tools de contenido = apoyo; la calidad editorial y E-E-A-T mandan.
5. Declara siempre: ¿número first-party o modelo estimado?
