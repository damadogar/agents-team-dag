# plantillas.md — Plantillas de entregables

Plantillas estándar de Brujula. Toda entrega termina con **"Próximos
pasos"** y **"Criterios de éxito medibles"**. Lo que cubra trabajo fuera del foco
central se marca **`[COBERTURA ADJUNTA]`** con su handoff (ver
[gobernanza-y-colaboracion.md](gobernanza-y-colaboracion.md) §4.1).

---

## 1. Informe ejecutivo (1 página)

```
# Informe — <tema>
Problema / contexto: ...
Recomendación: ...
Riesgo si no se actúa (decisiones con dato inconsistente): ...
Esfuerzo estimado: ...
Impacto en consumidores (dashboards/métricas): ...
Próximos pasos · Criterios de éxito medibles: ...
```

```
| A      |             |             |               |             |       |       |

Recomendación + porqué · Hallazgos · Próximos pasos · Criterios de éxito: ...
```

## 3. ADR semántico

```
# ADR-<n>: <título>
Estado: Propuesto | Aceptado | Reemplazado
Contexto (concepto de negocio, restricciones): ...
Decisión (modelado/métrica): ...
Alternativas consideradas (2-3) y por qué se descartaron: ...
Consecuencias (positivas/negativas, reversibilidad, impacto en consumidores): ...
Frontera/RACI: significado (PO/BA) vs implementación (brujula): ...
```

## 4. Diseño de modelos

```
# Diseño — <dominio/mart>
Objetivo y consumidores: ...
Diagrama (Mermaid estrella / bus matrix): ...
Hechos (grain explícito): fct_...
Dimensiones (conformadas): dim_...
Wide tables / agregados: obt_... / agg_...
Materializaciones: view | table | incremental | snapshot
Tests: unique, not_null, relationships, accepted_values
Documentación: descripciones de modelo/columnas
Próximos pasos · Criterios de éxito: ...
```

Ejemplo de diagrama:

```mermaid
flowchart TD
  FCT[fct_ventas\n(grain: línea de orden)]
  DIMC[dim_cliente]
  DIMP[dim_producto]
  DIMF[dim_fecha]
  DIMC --> FCT
  DIMP --> FCT
  DIMF --> FCT
```
