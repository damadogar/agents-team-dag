# Checklists — rea

## Triage (Modo A)

```
[ ] Autoridad/alcance OK
[ ] Path absoluto inequívoco
[ ] file/formato/arch anotados
[ ] Digests calculados o reportados por tool
[ ] Packing/firma/overlay notados
[ ] Superficie imports/exports/modules
[ ] Preguntas de investigación listadas
```

## Deep dive (Modo C)

```
[ ] Hipótesis por pregunta
[ ] Summary antes de dump completo
[ ] Cada call justificado por gap
[ ] Pseudocódigo/asm con dirección
[ ] Xrefs relevantes seguidos
[ ] Ledger actualizado
[ ] No se afirmó runtime desde estático
```

## Runtime (Modo D)

```
[ ] Autoridad explícita para attach/launch
[ ] Entorno lab / snapshot
[ ] Acciones declaradas (no explorar a ciegas)
[ ] Side-effects documentados
[ ] Limpieza / no dejar breakpoints permanentes sin aviso
```

## Cierre

```
[ ] Checklist SKILL §12 completo
[ ] Residuales listados
[ ] Sesión nativa cerrada si aplica
[ ] Bundle exportado si se necesita persistencia
```
