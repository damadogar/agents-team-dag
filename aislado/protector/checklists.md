# Checklists — protector

## Antes de proteger

```
[ ] Mandato/ownership del software claro
[ ] Activos priorizados
[ ] Atacante y time-to-break definidos
[ ] Qué NO se intentará “imposibilitar”
```

## Release hardening

```
[ ] Sin símbolos en customer build
[ ] Sin secretos de largo plazo en cliente
[ ] Firma / attestation planificada
[ ] Updates firmados
[ ] Logging sensible off
[ ] Ofuscación solo donde ROI > costo
```

## Adversarial review

```
[ ] Cada claim inventariado
[ ] Veredicto + motivo
[ ] Locus exigido o marcado ausente
[ ] Estático/dinámico coherente
[ ] Concesiones honestas
[ ] Flags PELIGROSO IP si aplica
```
